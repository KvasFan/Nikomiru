# Source tag 2.120.0 — M102–M119, 2026-11-17

Source tag `v2.110.0` / `e4a77c1` was the base. Eighteen sequential milestones add local TXT/Markdown/pasted text (M102), offline Mokuro volumes (M103), phrase vocabulary (M104), cloze exercises (M105), an offline sentence bank (M106), batch mining (M107), mining profiles (M108), pause lookup and held secondary tracks (M109), HTMLZ/RTF/DOCX/PDF documents (M110), annotations, library search and reading modes (M111), podcasts (M112), shortcut maps (M113), MDict rich content and media (M114), study-language profiles (M115), Emby (M116), touch gestures (M117), named palettes and Anime4K presets (M118) and signed application updates (M119). See [m102.md](m102.md), [m110.md](m110.md) and [m103-m119.md](m103-m119.md).

New dependencies: `minisign-verify` 0.3 (MIT) and the test-only `ed25519-compact` 2.6 (MIT), both listed in SPECIFICATION §4.

This is a source release. Stable Linux binary/package pins remain 2.53.0. Still open: native Windows/Android/macOS checks and AnkiDroid (M117), the maintainer's production minisign key and signed update feed (M119), and validation of Emby, MDict and podcasts with real servers and files.
