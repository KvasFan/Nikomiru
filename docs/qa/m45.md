# M45 — Selected support-tool installation, 2026-11-14

The setup assistant now offers FFmpeg/ffprobe, yt-dlp, Deno and the existing
local OCR model. Each component is optional; selecting yt-dlp resolves its
FFmpeg and Deno dependencies before the resolver. Standalone yt-dlp includes
Python/EJS, and OCR uses the existing Rust engine. Runtime playback, graphics
and TLS libraries remain package/system prerequisites.

## Installation and persistence

The catalog pins exact upstream URLs, SHA-256, downloaded sizes, executable
names, license and platform (Linux/Windows, x86_64/aarch64). Only Install can
start downloads; offline inventory and opening the wizard cannot. Working
configured, managed or system tools are reused and their paths adopted.
Downloads use the configured proxy and cancellation token. Extraction accepts
only allowlisted regular executable members, with compressed/uncompressed,
member-count, per-binary and decoder-memory bounds. Links, traversal and
duplicate executable names are rejected. Staging is removed on failure or
cancellation; publication retains/restores an old bundle when replacement
cannot complete. Download provenance stays beside installed executables.

The session persists tool paths before showing Done, reports save failures,
and immediately reconfigures subtitle, mining, library and thumbnail workers.
Web-video jobs explicitly pass the configured Deno and FFmpeg paths to yt-dlp.
Refresh permits reinstallation if a previously installed component disappears.
No system PATH or administrator-managed files are changed.

## Limits

Windows compilation is covered by CI; native Windows/ARM runtime checks are
not claimed. There is no new macOS/Android port. Driver/system-package updates
and automatic installation of the external Anki application/add-on are outside
this tool installer; the assistant retains its existing Anki setup instructions.
