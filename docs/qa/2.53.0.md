# Release 2.53.0 — M25…M44, 2026-11-14

This release combines the two requested ten-milestone batches. M25…M34 and
M35…M44 are complete; detailed behavior and per-milestone evidence are in
[m25-m34.md](m25-m34.md) and [m35-m44.md](m35-m44.md).

The final feature CI passed **886 tests**, 72 opt-in tests skipped. Targeted
actual GUI checks cover progressive/cancelled OCR, external VobSub, DVB,
book/series/episode counts, restart cache hits, encounter export/reset/cache
management and book/series report snapshots. No Rust dependency was added.
