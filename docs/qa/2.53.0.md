# Release 2.53.0 — M25…M44, 2026-11-14

This release combines the two requested ten-milestone batches. M25…M34 and
M35…M44 are complete; detailed behavior and per-milestone evidence are in
[m25-m34.md](m25-m34.md) and [m35-m44.md](m35-m44.md).

The final feature CI passed **886 tests**, 72 opt-in tests skipped. Targeted
actual GUI checks cover progressive/cancelled OCR, external VobSub, DVB,
book/series/episode counts, restart cache hits, encounter export/reset/cache
management and book/series report snapshots. No Rust dependency was added.

## Final release checks

- `cargo xtask ci --full`: **all green**, 481 s. **944** workspace tests
  passed, 14 external opt-ins skipped; **96** actual GUI tests passed, five
  L7/external cases filtered out. Fixtures, offline build, optimized build,
  Linux/Windows clippy, headers, translations, traceability and licenses passed.
- Release feature-tree/binary checks confirm no test harness is shipped.
- Generated `THIRD_PARTY_LICENSES.html` exactly matches the packaged copy.
- The native executable reports `nikomiru 2.53.0`. Dynamic runtime checks show
  **glibc 2.44**, **OpenSSL 4** and **libmpv.so.2**; the archive filename and
  runtime notes make these requirements explicit.
- The Flatpak builds against Freedesktop **26.08**. Its sandboxed executable
  reports **2.53.0**; runtime FFmpeg exposes both `dvdsub` and `dvbsub` encoders.
- Native/Flatpak binaries were built from `5a20bb3`; subsequent preparation
  changes only these validation records. Release archives include licenses
  and SHA-256 checksums. Package source pins/checksums are updated after the
  immutable tag is available.
