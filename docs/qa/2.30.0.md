## Scope and remaining checks

Word colouring must be enabled, as for the existing episode scores. Local
external and embedded text subtitles are supported. Graphic tracks remain
unscored and never trigger background OCR; remote videos are not probed for
scores. Reopening a series refreshes source selection and file metadata;
language/tool changes start a new count epoch. A cached count is rescored when
word statuses change.

The probe cache is bounded to 256 video signatures; count storage retains its
256-file bound. Embedded extraction uses a separate cache directory to avoid
competing writes with playback, and shutdown cancels active processes and
drops queued episodes.

Series-card scores, whole-book scores before opening and new words met per
episode remain on M21's roadmap. A large real Japanese series with mixed
container formats and Windows runtime behavior still need manual validation;
the Windows check verifies compilation.

No Rust dependency, database schema or persisted configuration field was added.
