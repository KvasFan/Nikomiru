# M102 — TXT, Markdown and pasted-text reading

Branch: `development/m102-text-reader`, based on source tag v2.110.0. Requirements BOK-011…BOK-014 and test cases were written before implementation. This is development work in Unreleased, not a new published source/binary release.

## Feature validation

- Parser tests passed: UTF-8/BOM/CRLF, literal text, headings/links/code/ruby, control/byte/paragraph limits, identity, atomic save failure and invalid managed format.
- Fast CI passed 994 tests (73 external opt-ins skipped), including component editor submission and real dictionary whole-book segmentation. Pasted-source backup/restore is covered by the existing backup round-trip tests.
- Two actual-app cases passed: Markdown lookup/internal card creation, real scrolling and moved-file/restart position retention, whole-book analysis, invalid UTF-8 preserving the current reader; pasted-source restart, identity isolation/reuse and an actual filesystem write failure preserving the active document.
- New dependencies: MIT pulldown-cmark 0.13.6 with default features disabled and MIT/Apache unicase 2.10.0. Existing serde/serde_json/sha2 are reused. Dependency rationale/alternative evaluation is in SPECIFICATION; packaged notices and Flatpak registry sources were regenerated.

## Final regression

`cargo xtask ci --full` passed in **462 seconds**: **1,052 workspace/integration tests passed** (15 external opt-ins skipped), **109 actual GUI cases passed** (five external L7 cases filtered). Formatting, Linux/Windows clippy, architecture, headers, all three translations, traceability, fixtures, offline and optimized builds passed. The release-build startup/no-harness checks passed. Fresh third-party notice generation matches the packaged HTML byte for byte.

M102 is complete in development and remains in Unreleased on `development/m102-text-reader`. Published source/binary tags are unchanged.
