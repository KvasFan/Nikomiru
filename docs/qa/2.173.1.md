# 2.173.1: manga columns left unread, 2026-11-19

Base: `v2.173.0`. The maintainer showed a page of a real volume (Kaiji volume 1, page 8) where some balloons kept their original text: a large first column (脱税), a short column (元に) and columns of dots were not read, and some dots were covered without being written again. Recorded as [AK-BUG-008](../bugs/AK-BUG-008.md).

## How it was checked

- **The page itself**: `l7_a_real_manga_is_read_ahead` on Kaiji volume 1 page 8 in the real app: all ten balloons whole, among them 脱税しまくってるよーな奴だ．．．． and 今おまえの元に帰ったんだよ．．．．．．．．．; seen by eye on the screenshot.
- **No regression**: the same 30 pages of Nana volume 1 as for 2.163.0 (pages 10–39, 356 blocks), measured with the same script, and each block compared with the 2.163.0 run.
- **Another artist**: Kaiji volume 1, pages 5–24 (253 blocks), measured and the worst blocks seen by eye.

## Results

| | 2.163.0 | 2.173.1 |
|---|---|---|
| Nana: uncovered ink near a block, median / 90th percentile | 0.036 / 0.318 | 0.034 / 0.308 |
| Nana: characters' size / original line width, median / 10th percentile | 0.93 / 0.77 | 0.93 / 0.77 |
| Nana: blocks whose text gained what was missing | — | 11 |
| Kaiji 5–24: uncovered ink, median / 90th percentile | — | 0.011 / 0.344 |
| Kaiji 5–24: characters' size / original line width, median / 10th percentile | — | 0.95 / 0.77 |

- In Nana, the text that came back is real: よく１人で, さわがしー, あ章司？, だけど．．．いいの？ and more.
- A first run of the fix also read the furigana こく and a balloon's outline as text; both were found in the comparison, and the rules were made stricter (a narrow column is dots only when its ink is in short pieces, each alone, white past both edges). Some columns of dots are therefore still covered without being written again, as before.
- The worst Kaiji blocks by the measure are covered whole; what it counts is the screentone around the balloons.

## Final regression

`cargo xtask ci --full`: **all green in 569 seconds**, with **144 actual GUI cases passed**.
