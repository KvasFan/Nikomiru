# Ten further study milestones — 2026-11-14

The maintainer requested M35…M44 while M34 was under validation. M25…M34
are complete; work continues consecutively on `development/m25-m44`.

## M35 — Normalised study/subtitle search

A separate display-search query folds NFKC width/composition, lowercase and
basic katakana/hiragana while preserving long-vowel marks. Every whitespace
term must match a display field. Original cue indices, offsets and word keys
remain untouched. Tests cover half-width kana/dakuten, decomposed dakuten,
full-width ASCII, case, multi-field terms, empty queries, vocabulary reading
search, historical filtering and subtitle target identity. No dependency added.

M35: `cargo xtask ci` passed, **874 tests passed**, 72 skipped.

## M36 — Vocabulary status/card filters

targets, and shown export snapshots with exact status/card constraints. No

## M37 — Vocabulary ordering

filter intersections and hidden selected identities. A component case changes

M37: `cargo xtask ci` passed, **876 tests passed**, 72 skipped.

## M38 — Copy study vocabulary

shown/selected click. It reuses bounded sanitised TSV and current ordering,
with visible success/limit feedback. The component test inspects actual egui
clipboard output for filtered rows and hidden selected rows, checks no empty
selection output, keeps ticks and emits no word-status command. Native

## M39 — Full episode encounter export

The native save dialog captures a media uid; the library worker reads only
that episode's full history at save time. Export includes rows beyond the
1,000 display cap, newest first, with original timestamps and neutralised
fields. Tests cover the full bounded TSV and accessible action; the real GUI
case checks an actual worker-written file before clearing history, preserving
the independently known word status. Atomic output uses the existing writer.

M39: `cargo xtask ci` passed (**878 tests**, 72 skipped); the actual GUI
full-history export/clear case also passed.
