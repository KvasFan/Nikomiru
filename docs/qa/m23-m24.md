# M23 and M24 — validation, 2026-11-12

M23 implements PLY-022 and AUD-010; M24 implements PLY-023 and reuses ANK-050.
The source releases are prepared locally; no tag, package or release is published.

## Automated checks

Final results: **808 workspace tests passed** (70 opt-in tests skipped),
**84 GUI tests passed** (5 external/live checks filtered out), and the live
YouTube smoke check below passed. The optimized `target/release/nikomiru`
binary was built and reports **2.28.0**.

- `cargo xtask ci`: formatting, clippy on Linux and Windows, architecture,
  interface strings, licensing, traceability, Flatpak sources and workspace tests.
- `cargo test -p nikomiru-media --test condense_l4 -- --include-ignored`: real
  Opus and MP3, duration and chapter text/times, selected audio frequency,
  name reservation, cancellation and failure cleanup.
- `cargo test -p nikomiru-app --test condense_l4 -- --include-ignored`: a
  series with saved external subtitles, embedded Japanese text subtitles and a
  silent episode; successful exports and per-episode errors.
- `cargo test -p nikomiru-app --test web_video_l4`: fake yt-dlp and local HTTP
  media/subtitles, fixed arguments and proxy, no request at startup, missing
  executable, cancellation and metadata with a description larger than 64 KiB.
- Real-player tests in `tests/e2e/{gaps,condense,web_video}.rs`: speed restoration,
  pause/replay/popups/hold-to-speed, no temporary speed saved, captured export
  preserved across a file change, web video with separate audio, card with audio
  and image, and source link reopened after restart. Missing/cancelled web opens
  leave local playback usable.

## Live YouTube smoke check

The opt-in `web_video_l7` test passed with yt-dlp **2026.10.26**, the system
ffmpeg and the public NHK video <https://www.youtube.com/watch?v=3gmoZHWo8dE>:

- 66 Japanese subtitle cues read by the ordinary subtitle loader;
- the first cue's frame extracted as PNG through the video relay;
- the first cue's audio extracted as M4A through the separate audio relay;
- the stable uid derived from the original page URL.

The executable used for this check is temporary and is not bundled. Reproduce
with a currently available public Japanese video:

```sh
NIKOMIRU_TEST_WEB_VIDEO_URL='https://www.youtube.com/watch?v=…' \
NIKOMIRU_TEST_YT_DLP=/path/to/yt-dlp \
cargo test -p nikomiru-app --test web_video_l7 -- --include-ignored --nocapture
```

This check caught a real integration problem: full yt-dlp metadata exceeded the
process runner's 64 KiB stdout limit. The request now prints only the selected
streams and fields needed by the player, using yt-dlp's documented
[dictionary output template](https://github.com/yt-dlp/yt-dlp#output-template).
The large-description regression above prevents a return to full metadata.

The full GUI suite also caught [AK-BUG-006](../bugs/AK-BUG-006.md): queued audio
could make a 4× → 1× restoration reach the next line. The lead now accounts for
the rate difference, and the player test requires restoration before speech.
