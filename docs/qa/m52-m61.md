# Ten milestones after source tag 2.60.0 — 2026-11-14

The maintainer requested tag/push and ten further milestones at M51.
`v2.60.0` / `3148b8d` was verified on the remote; continuation on
`development/m52-m61` completes M52…M61, preserving the M52…M55 plan.

## M52 — Vocabulary coverage summary

Shared lists display shown/total distinct words and occurrence tokens, token
coverage and selected word/token counts including hidden ticks. Wide integer
sums and unavailable zero-denominator ratios are covered, together with actual
accessible metrics under filters. `cargo xtask ci`: **906 tests passed**,
73 opt-ins skipped.

## M53 — Dictionary lookup from study vocabulary

Each row dispatches an explicit expression/anchor lookup without attaching an
unrelated cue. The root generation identifies study popups, which render above
the library while other settings continue covering them. The actual GUI opens
a dictionary result before media and closes it with Escape; ticks remain intact
in component tests. `cargo xtask ci`: **907 tests passed**, 73 opt-ins skipped;
the actual no-media/library lookup case passed.

## M54 — Subtitle word concordance

Examples match segmented headword/reading identities, including inflections.
Partial/evicted segmentation never produces guessed results. Primary source
and word revisions invalidate captures; entering examples switches to Lines
and clears its old word query while retaining other line filters. Logic and
accessible scope/clear checks pass. `cargo xtask ci`: **909 tests passed**,
73 opt-ins skipped; the added view case and actual inflection/clear/source-
replacement GUI case also passed.

## M55 — Study frequency dictionary export

Shown/selected rows freeze a complete bounded Yomitan v3 ZIP with source title,
separate readings and occurrence-based counts. Streaming JSON/output bounds,
duplicate/invalid identity rejection and readable metadata are covered. The
existing importer/store preserves frequencies after reimport; the actual app
exports its analysed vocabulary through native save and that ZIP reimports
with the expected inflected-headword count. No automatic dictionary install.
`cargo xtask ci`: **913 tests passed**, 73 opt-ins skipped; actual GUI passed.

## M56 — Exact vocabulary search

Whole-field matching reuses Unicode width/kana/case folding, retains original
spelling and never combines different fields into an exact match. The accessible
toggle composes with all filters and preserves hidden ticks. `cargo xtask ci`:
**915 tests passed**, 73 opt-ins skipped.

## M57 — Subtitle reading-speed filters

Optional character/second bounds compare exact integer ratios over full cue
duration, counting Unicode scalar values rather than UTF-8 bytes and excluding
whitespace. Scope caching includes both time and speed filters. Threshold,
non-BMP, zero-duration/extreme-time, reset and hidden-selection tests pass.
`cargo xtask ci`: **917 tests passed**, 73 opt-ins skipped.

## M58 — Subtitle study statistics

Shown/selected metrics count original cues and non-whitespace Unicode values;
dialogue duration unions overlaps after delay and zero clipping. Invalid or
large scopes return no partial totals. View metrics cache on scope/source/word
revision and selection changes, independently of playback ticks. Union, empty,
overflow and accessible hidden-selection/filter refresh checks pass.
`cargo xtask ci`: **919 tests passed**, 73 opt-ins skipped.

## M59 — Bilingual SRT export

TSV and combined SRT now share one bounded overlap-pairing implementation.
Combined captions retain primary timing, add distinct translations as text
lines and preserve untranslated primary cues. Source snapshots and native
SRT filenames remain distinct. `cargo xtask ci`: **921 tests passed**,
73 opt-ins skipped; actual bilingual SRT/TSV scoped exports passed.
