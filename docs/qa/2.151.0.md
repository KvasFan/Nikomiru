# Source tag 2.151.0 — OCR speed and audio download retries, 2026-11-18

Base: release `v2.150.0`. The maintainer reported that reading text with the OCR was slow, and that installing the local word audio failed past about 570 MB.

## OCR (MNG-003)

Measured with `examples/ocr_bench.rs` (optimised build, the installed manga-ocr model, the same machine load of about 15):

| | Load | One balloon of 8 characters |
|---|---|---|
| 2.150.0 | 0.6 s | 1.57–1.69 s |
| 2.151.0 | 1.1 s, in the background when the reader or line tools open | 0.83–1.08 s |

- The decoder was an inference plan whose shapes tract worked out again at every token. It is now typed and optimised once, with the token count as a symbol.
- Matrix products run on half the cores, at most 8. This uses `tract-linalg`'s `multithread-mm` feature; the crate is already in the graph through tract, and rayon was already there.
- The model loads in the background when the reading page or the player's line tools open.
- Graphic subtitles were already read one picture per thread, so they keep one thread per picture.
- The L7 check with the real model reads 「日も食べました」 in 14 s in the unoptimised test build, against 35 s before.

## Word audio download (INS-004)

- **Reproduction attempt:** with the app's own code, the bytes of both libraries between 512 and 640 MiB were read from Fushi's real pack without an error. Some 16 MiB pieces took 12 s, so a server can slow down. On this machine `android.db` was installed whole at 17:54 the same day and added to the sources.
- **Change:** each piece of the pack is now tried in six rounds at every address, the waits doubling from 2 s, about a minute in all; before, it was three rounds with 2 s and 4 s waits. A download that still stops keeps its `.part` and goes on from there.
- **Tests:** an L4 test checks that a piece failing at both addresses for five rounds still comes in the sixth, and that a sixth failure in a row ends the download with the `.part` kept. An L7 test reads the real pack's libraries past their first parts.
- **Open:** the exact message the maintainer saw is not known.

## Final regression

`cargo xtask ci --full`: **all green in 685 seconds**. **1,195 workspace/integration tests passed** (17 external opt-ins skipped) and **142 actual GUI cases passed** (six external L7 cases filtered out). The run waited for the machine's load to fall below 8. The first run stopped at `cargo fmt --check` on the new tests, before any test ran.
