# Source tag 2.130.0 — M120 and release tooling, 2026-11-18

Base: published release `v2.120.0` / `250cc5e`. The maintainer asked to complete the remaining features (D-66). Everything implementable on Linux is in this tag:

- **M120, AniDB file identification (MET-006).** "Identify by file (AniDB)" hashes an episode (ed2k) and asks AniDB's UDP API with the user's account. AniDB's titles are then found on AniList or Jikan. See [ROADMAP M120](../ROADMAP.md#m120--anidb-file-identification).
- **Signed updates from the published archives (UPD-004).** The installer did not find the program in archives whose files sit in a `Nikomiru-<version>/` top folder, which is how the published ZIP and Linux archives are made. A single top folder is now taken as the install's content; tested with `.zip` and `.tar.xz`.
- **Release tooling.** `cargo xtask linux` (`.tar.gz` and `.tar.xz`), `cargo xtask update-manifest`, and the Windows MSI from `cargo xtask windows`. Release programs never carry the build machine's paths. The steps are in [RELEASING](../RELEASING.md).
- **Traceability.** `cargo xtask trace` expands ID ranges in test comments. The four requirements that showed no linked tests (AUD-009, BOK-003, SUB-020, SRV-016) were all covered; their tests are now linked, with an added check for AUD-009's `♪?`.

## Checks

- AniDB: AniDB's published ed2k vectors for both variants, protocol tests against a fake UDP AniDB, the series and services page components, and an actual-app identification (fake AniDB and AniList) all passed. No real AniDB check: Nikomiru's client is not registered yet.
- `cargo xtask linux` produced 2.120.0 archives as a trial, and `update-manifest` wrote a manifest for them. Nothing was signed or published: the production key does not exist.

## Final regression

- `cargo xtask ci --full`: **all green in 482 seconds**. **1,170 workspace/integration tests passed** (16 external opt-ins skipped) and **139 actual GUI cases passed** (five external L7 cases filtered out). This includes formatting, Linux/Windows clippy, translations, licenses, traceability, Flatpak sources, offline/optimized builds and the third-party notices.

- **Native Linux x86_64:** `cargo xtask linux` wrote the `.tar.gz` and the `.tar.xz` the signed updater installs; the program reports `nikomiru 2.130.0` and needs **glibc 2.44**, **OpenSSL 4** and **libmpv.so.2**.
- **Flatpak:** Freedesktop Platform **26.08**; the installed bundle reports `nikomiru 2.130.0`.
- **Windows x86_64 preview ZIP and MSI:** `cargo xtask windows` with shinchiro libmpv `20261103-git-a687796d9d` and BtbN FFmpeg `n8.1.3-32`; no build-machine path in `nikomiru.exe`; it reports `nikomiru 2.130.0` under Wine. Under Wine the MSI installs silently under Program Files, the installed program reports `nikomiru 2.130.0`, and it uninstalls leaving no folder. **Not checked on a real Windows.**
