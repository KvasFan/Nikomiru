# Source tag 2.150.0 — M127, 2026-11-18

Base: source tag `v2.140.0` / `8f56fc4`. The maintainer asked for the main page in tabs, no overlapping text and a better look, for manga words looked up directly, and for furigana of web pages to stay on their line (D-77).

- **Shelves (VID-001, VID-002, BOK-015).** The main page has these tabs: Collection, Videos, Books, Manga, Websites, then Statistics, the Review and media servers. The Videos tab holds the history of videos opened on their own and saved links. Books, manga and web pages each have their own tab, and closing the reader goes back to it. The tools are in one menu.
- **No overlapping text.** The tabs and each tab's actions have rows of their own. In list rows, episode rows and the reading page's header, the buttons are laid out first and the text is cut before them. The series controls fit on one wrapping row.
- **Manga (MNG-010).** A click on a word of a Mokuro page looks it up through Mokuro's line boxes. A box dragged over a page is read and its first word opens in the dictionary. Without the model, the drag says the model is needed instead of doing nothing.
- **Furigana (WEB-004).** HTML white space is collapsed, and `</rt>` may be left out. Readings are placed from the glyphs themselves, so a word that ends its line keeps its reading on that line.

## Note on the CBZ report

In the actual app with the stand-in text and with the real model, a drag over a CBZ page reads the text. The text was then shown above the page, but nothing opened by itself, and without the model a drag did nothing. Both have changed: the dictionary now opens on the first word, and a drag without the model shows a message.

## Final regression

- `cargo xtask ci --full`: **all green in 440 seconds**, on an idle machine. **1,194 workspace/integration tests passed** (16 external opt-ins skipped) and **142 actual GUI cases passed** (six external L7 cases filtered out).
- The earlier full runs stopped for these reasons:
  - **Untranslated strings.** Three literal strings were caught by the interface-strings check: the page name and two address hints. They now come from the string files.
  - **A duplicate requirement ID.** The shelves first reused BOK-004, which belongs to M16, so they are now BOK-015.
  - **Tests reading the pause position too early.** One test read the playback position as soon as the state said paused. mpv reports the final position a moment later (0.125 s against 0.208 s). The five tests that compared a paused position now wait for it to settle (`paused_settled`).
  - **Another project compiling on the machine.** Two runs failed while another project compiled in parallel (load 16–30): the Wayland drag of files once, and T-PERF-02 once (1.59 s to the first frame). Run alone, the drag test passed three times out of three. The first frame measured 44–172 ms three times. The final run waited for the load to fall below 6.
