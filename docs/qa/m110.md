# M110 — Additional local documents

Branch: `development/m103-m119`; requirements DOC-001…DOC-005 and [ADR 0010](../adr/0010-document-imports.md) precede the implementation. This remains Unreleased; source/binary versions and published package pins are unchanged.

## Format and native checks

- HTMLZ tests use real ZIP archives and HTML/ruby. They verify deterministic main-document selection, inert script/link/image handling, unsafe/case-duplicate names, ambiguous roots and selected-entry/archive quotas.
- RTF tests cover scoped font/code-page state, strict native CP932/CP1252 decoding, Unicode fallback counts, signed surrogate pairs, escaped syntax, binary/ignored destinations, visible field results and Unicode alternatives. Malformed groups, numbers, Unicode and decoding fail without partial reader output.
- DOCX tests use real ZIP/WordprocessingML in transitional and strict namespaces. They verify run/table order, headings, Unicode/XML entities/CDATA, revisions and field results, inert external parts, invalid/duplicate/undeclared attributes, text outside the root and XML/archive/paragraph budgets.
- Actual installed **Poppler 26.10.0** extracts the project-generated Japanese ToUnicode fixture, preserves an empty middle page and shares exact source identity/paragraphs with whole-book analysis. No-text, password-required, invalid and unavailable-helper cases are rejected. Fixtures contain no external document or embedded font program.
- Fake executables exercise actual bounded stdin/stdout/stderr, invalid UTF-8/version validation, cancellation, output limits and physical deadlines. A wrapper exiting while a descendant holds its pipes open cannot bypass the deadline; Linux cleanup terminates the dedicated helper group. Extraction uses frozen bytes and a fixed argument vector, without shell evaluation.
- Native package-plan tests exercise fixed pacman/apt-get/dnf/zypper arguments and preflight cancellation through a harmless fake authenticator. The accessible Setup component names the system-package action, requires explicit selection and disables unavailable installation. No privileged package installation was performed during validation; actual distribution transactions and sandbox/native platform packaging remain manual/platform checks.

## Actual application checks

Five new off-screen native-app cases passed. HTMLZ, RTF and DOCX each exercise import, dictionary lookup, internal card creation, exact sentence-bank sources, invalid-import isolation, whole-book analysis, scrolling and reading-position restart. The RTF case uses real native Japanese CP932 decoding as well as Unicode escapes.

The PDF case checks original page indices through an empty page, dictionary lookup/card creation, phrase capture/source navigation across restart, whole-document sentence indexing, analysis and failed no-text/password/invalid imports retaining the active reader. A separate Setup case starts with a missing configured helper, explicitly adopts installed Poppler, updates the live reader and analysis adapter, and proves persisted configuration wins over a changed environment after restart. It does not install an OS package or elevate.

## Limits

HTMLZ imports one selected HTML document. RTF/DOCX preserve supported text structure, rather than rich office layout, embedded objects or macros. PDF imports text only, with no OCR or complex visual-order reconstruction. Original files remain user-owned; bodies are not added to backups/WebDAV and no database migration is introduced. Broader real-document comparisons and native Windows/macOS/Android/sandbox packaging remain open under the existing roadmap.

## Final regression

`cargo xtask ci --full` passed in **526 seconds**: **1,102 workspace/integration tests passed** (15 external opt-ins skipped), **128 actual GUI cases passed** (five external L7 cases filtered). Formatting, Linux/Windows clippy, architecture/headers, all three translations, dependency licenses, traceability, fixtures, offline and optimized non-harness builds passed. The optimized executable reports `nikomiru 2.110.0` and passed the native startup/shutdown test. M110 is complete in development. Published versions and package pins are unchanged; M111 is the next accepted milestone.
