# Source tag 2.140.0 — M121…M125, 2026-11-18

Base: published release `v2.130.0` / `dba3a23`. The maintainer decided the open questions (D-70) and asked for speech, translation, explanation, shadowing and text from the picture (D-71…D-75), and for a proposal for device linking (D-76).

- **M121, subtitles from the speech (SUB-062, INS-008).** whisper.cpp v1.9.5 and the Whisper large-v3-turbo model come from the setup assistant. "Generate from the audio (Whisper)" reads the current audio track on this computer and shows the SRT, which is kept with the video's subtitles.
- **M122, translation (TRN-001, TRN-002).** DeepL translates the line using the user's key. The line tools panel works on the current line.
- **M123, explanation (AIX-001, AIX-002).** Claude's Messages API explains the line using the user's key, with `claude-opus-5-5` as the default model.
- **M124, shadowing (SHD-001, SHD-002).** The microphone is recorded through ffmpeg, read by whisper.cpp and scored against the line; the recording can be played back.
- **M125, text from the picture (OCR-001).** A dragged part of the frame is read by the local OCR model and looked up like a Texthooker line.
- **M126, device linking.** This is a proposal only: [ADR 0011](../adr/0011-device-linking.md).
- **Decisions.** ADR 0004 and D-18 are accepted. The X11 measurement stays open as it is.

## Checks

- **Unit tests:**
  - the request builders for DeepL and Claude, and how their answers are read;
  - the ffmpeg and whisper-cli arguments, the progress lines, the microphone input and the shadowing score;
  - the recording length, the area of the picture, and the line stamps.
- **Tests against fakes (L4):**
  - DeepL and Claude: keys, headers, bodies and errors, with nothing sent when there is no key;
  - a `.tar.gz` installs its libraries under the names programs load them by and never writes a link.
- **Component tests (L3):** the line tools panel, the services page keys, the Advanced speech settings, and the setup assistant's whisper.cpp and speech model items.
- **Actual app (L6):**
  - a stand-in `whisper-cli` reads a video's speech, and the SRT is stored and shown;
  - the line is translated by a fake DeepL and explained by a fake Claude;
  - shadowing records through ffmpeg's test microphone and scores 80 %;
  - text read from the frame is looked up;
  - nothing is sent before it is asked for.
- **Real whisper.cpp (L7):** the pinned Linux x86_64 archive downloaded, hash-checked, extracted with its renamed libraries, and its `whisper-cli --version` ran. On this machine, the minimal file set with the base model also transcribed whisper.cpp's sample `jfk.wav` into SRT, with and without the voice-activity model.
