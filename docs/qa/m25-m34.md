# Ten consecutive milestones — 2026-11-14

The maintainer selected subtitles and study tools for M25…M34. Work proceeds
in order on `development/m25-m34`; AI/speech services and ports are excluded.
This is an active development batch, not ten completed/public releases.

## M25 — Progressive graphic OCR

The captured playback position determines which pictures are read first.
Batches contain at most 16 cues and publish cumulative ordered text. Partial
text supports lookup; popup cue identities are remapped by text and time when
earlier cues are inserted or identical neighbours join. The offset is kept.
Unread active cues retain mpv's pictures. Disabling/replacing subtitles or
closing the loader cancels the old work; stale reports are ignored.

Partial timelines do not produce whole-track scores, condensed exports or
gap acceleration. Changing partial cue ids does not add character credits.
Only complete, nonempty, uncancelled OCR commits the final SRT cache. Failed
batches may be skipped, as in whole-track OCR; an entirely failed reading
falls back to the images and never caches a partial/error result.

Checks include priority/batch/final-equivalence/cancellation/error tests,
cue identity mapping and an actual ffmpeg/GUI case with delayed test OCR,
lookup across snapshots, stale-source replacement and cache completeness.
A real graphic subtitle track still needs a manual comparison.

M25 automated validation passed: `cargo xtask ci` reports **850 passed**,
71 skipped, including Linux/Windows clippy, headers, translations, licensing
and traceability. The delayed actual ffmpeg/GUI case passes, including the
absence of a cache for cancelled reading and suppression of partial exports.
The workspace version is a development version until this ten-milestone
batch is ready for a release.

## M26 — External VobSub pairs

The same-stem local companion is resolved case-insensitively. The pure index
parser selects preferred/default language, filters sparse MPEG private stream
ids and uses index timestamps rather than packet PTS. Invalid records and
offsets fail as a whole. Both source signatures and the selected stream are
part of the OCR cache key. Saved explicit choices restore on reopening; these
files never trigger background score probing/OCR.

`cargo xtask ci`: **854 passed**, 71 skipped, with Linux/Windows clippy and
the repository checks green. The actual GUI case passes for both members,
preferred-language decoding, lookup, reopening the saved choice, changed
valid/invalid companions and missing files. Exactly the two complete valid
pair versions produce cache entries. The explicit score-exclusion regression
also passes. Real external DVD subtitles remain a manual comparison.

## M27 — Embedded DVB bitmap subtitles

FFmpeg's documented [DVD subtitle encoder palette](https://ffmpeg.org/ffmpeg-codecs.html#dvdsub-1)
provides the explicit palette used by both the conversion and local parser.
`cargo xtask ci` passes; the real FFmpeg integration test passes both cases
(arguments/cache isolation and DVB conversion/timing/cancellation). The GUI
case reads an embedded DVB stream, offers both bitmap/text choices and opens
a dictionary lookup from the recognised text. Real broadcast material still
needs a manual comparison; teletext is not included.

## M28 — Cancel book and series analyses

Each retained analysis owns a request token; dropping/invalidating it stops
queued work and active reads, segmentation and child processes. The worker
combines that token with shutdown without cancelling ordinary episode jobs.
Pure tests cover cancel during series metadata loading and episode counting,
queue removal, late answers and immediate restart. Component tests exercise
both accessible Cancel buttons. No cancelled partial count enters a cache.

M28: `cargo xtask ci` passed, **858 tests passed**, 72 skipped.

## M29 — Whole-book study words

The vocabulary is derived from the retained complete count, with occurrence
totals across paragraphs and live shared status/card marks. The Books list
opens a dedicated vocabulary view without touching reader state. Tests cover
frequency aggregation, rescoring without a new job, no partial/refresh list,
accessible navigation, selecting all and bulk marking, and automatic closure
on refresh. Search/filter/status controls reuse the tested subtitle widget.

M29: `cargo xtask ci` passed, **860 tests passed**, 72 skipped.
